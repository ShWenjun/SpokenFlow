# 问题与帮助 / Support

## 中文

首次使用请阅读[使用指南](docs/USAGE.md)。没有浮窗或读取范围不符合预期时，先运行兼容性检测，再查看[兼容性矩阵](docs/COMPATIBILITY.md)。服务连接问题见[模型设置](docs/PROVIDERS.md)。

提交 Issue 前请搜索已有问题。按实际情况选择问题与兼容性、翻译与界面文字、功能建议或使用求助模板。

报告应包含 SpokenFlow 版本、Windows 版本、目标软件与输入法版本、操作步骤，以及不含私人内容的固定例句。翻译问题另附语言组合、模型名称、预期和实际结果。不要上传 API Key、完整用户配置或真实聊天记录。

API 余额、账号和模型权限由服务商处理。安全漏洞按 [SECURITY.md](SECURITY.md) 私下报告，不在公开 Issue 中披露细节。项目采用社区维护方式，不承诺回复时间。

## English

Start with the [usage guide](docs/USAGE.md). For a missing popup or incorrect capture scope, run compatibility inspection and check the [matrix](docs/COMPATIBILITY.md). Connection setup is covered in [model services](docs/PROVIDERS.md).

Search existing issues before filing one. Choose the bug/compatibility, translation/UI wording, feature proposal or usage-help template.

Include SpokenFlow and Windows versions, target application and input-method versions, steps and a synthetic example. Translation reports should also include the language pair, model, expected result and actual result. Do not upload API keys, full user settings or private conversations.

Contact the provider for account, balance or model-access issues. Report vulnerabilities privately under [SECURITY.md](SECURITY.md). This is a community-maintained project without a guaranteed response time.
