# 个人标识与名称 / Personal identity and branding

此文件规定个人标识与项目名称的使用范围，不扩大代码许可允许的用途。

This policy defines permitted use of the personal mark and project name. It does not expand the uses allowed by the code license.

`assets/SpokenFlow.png`、`assets/SpokenFlow.ico` 是 SpokenFlow 的专用组合图标，以双语对话气泡为主体；其中隐嵌的条纹飞鸟与红色圆点源于作者个人标识。个人标识及组合图标的权利单独保留，不适用代码的修改授权。SpokenFlow 名称用于识别本项目，不表示已经注册商标。

The personal bird/red-dot mark and composite icon are separately reserved to ShWenjun to the extent of applicable rights. Code modification permissions do not license these artwork modifications. No registered-trademark status is asserted for the project name.

允许的使用 / Permitted uses

- 官方项目文档、官方程序包和准确介绍本项目的截图，可展示原样标识。Official documentation/packages and truthful project screenshots may display the unaltered mark.
- 在代码许可允许的非商业范围内，可以保留完整官方源码镜像或 GitHub fork 中原样的标识文件，清楚注明来源；这不允许将其作为另一个项目的身份。Noncommercial source mirrors/forks may retain original files with provenance, not adopt them as another project's identity.
- 为个人非商业测试从源码构建，可以保留原样图标。Noncommercial personal test builds may retain the original icon.
- 无修改地分发官方版本，可保留图标，但须遵守代码许可的非商业及对应源码义务，不得暗示额外背书。Unmodified official redistribution may retain branding subject to code-license obligations and no misleading endorsement.

发布修改版程序时，请使用自己的名称和图标，明确“基于 SpokenFlow”，保留必要版权声明。构建脚本允许不提供 `assets/SpokenFlow.ico`，此时程序使用系统回退图标。仅删除或替换图标不改变代码的非商业限制。

Published modified executables must use distinct identity/icon and identify their basis in SpokenFlow. Omitting the ICO is supported by the build; the app falls back to a system icon. Rebranding does not remove the code's noncommercial conditions.

其他使用、修改个人标识或暗示官方关系需取得另行许可。不得冒用作者身份。法定合理使用等权利不受本政策限制。修改版保留原样标识文件作来源记录的权限，不等于展示它为修改版品牌的权限。

Other uses, artwork modification or implied affiliation require separate permission. Statutory exceptions remain unaffected. Keeping source provenance is distinct from branding a modified product.
